# Daimon｜知命・知己・知行

**看懂你的命盤，帶著真實近況，把眼前的問題說清楚。**

[免費開始](https://daimon.quest/beta?utm_campaign=first100&utm_source=github&utm_content=chart) · [會員方案](https://daimon.quest/pricing) · [使用回饋](https://github.com/wyonliu/Daimon/issues/1)

Daimon以八字四柱為起點，呈現排盤依據，連接日常記錄、關係合盤、通勝擇日、家宅方位與起名。你可以帶著具體的工作或生活問題，選擇是否使用AI解讀，再整理需要核實的條件與下一步。繁體中文與英文均可使用。

## 第一次來

1. [看看入門說明](https://daimon.quest/beta?utm_campaign=first100&utm_source=github&utm_content=chart)。免費體驗不需要帳戶或信用卡。
2. 填寫自己的出生資料；不知道時辰就保留未知。先查看計算出的命盤，再決定是否允許AI解讀。
3. 帶入一件具體的事，例如「兩份工作邀請，薪資和加班條件不同，我該先問清什麼？」記下有用的觀察，再回來核對。

想先讀一個不用填資料的問題，可以打開[先聽，還是先幫？](https://daimon.quest/together/listen-first?utm_campaign=first100&utm_source=github&utm_content=relationship)。這是公開的對話題，不會替收卡者排盤或判定關係。

## 先說清楚

八字是文化探索與自省的工具，不承諾預測人生事件；AI也可能出錯。七章長篇解讀仍為實驗功能，未完成不扣解讀額度。西方星座參照不包含完整行星、上升與宮位分析。

本機記錄、可選雲端備份、AI處理與匿名統計各有不同資料範圍，詳見[私隱說明](https://daimon.quest/privacy)。請勿在公開Issue貼出生資料、私人對話、付款資訊或登入連結。帳戶與退款問題請使用官網列出的支援郵箱。
